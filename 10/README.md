# Equation

Find all roots of the cubic equation A·x³ + B·x² + C·x + D = 0. All roots are known to be
integers in the range [-100, 100], so they can be found by brute force.

**Input** (`input.txt`): four integers A, B, C, D (each |value| < 32768, A ≠ 0).
**Output** (`output.txt`): all roots in increasing order separated by spaces; a repeated
root is printed only once.

Examples: `1 -3 0 0` → `0 3`, `1 -7 -33 135` → `-5 3 9`.
