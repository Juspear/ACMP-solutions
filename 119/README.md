# Sorting time

Several moments of time are given, each as hours, minutes and seconds. Sort them in
non-decreasing order and print them without leading zeros.

**Input** (`input.txt`): the number N (1 ≤ N ≤ 100), then N lines with three integers each: hours (0–23), minutes (0–59), seconds (0–59).
**Output** (`output.txt`): the sorted moments, one per line, without leading zeros.

Examples: `4 / 10 20 30 / 7 30 00 / 23 59 59 / 13 30 30` → `7 30 0 / 10 20 30 / 13 30 30 / 23 59 59`.
