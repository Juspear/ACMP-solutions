# Traffic lights

A dungeon has N junctions and M tunnels, each tunnel connecting two different junctions.
A traffic light is placed in every tunnel in front of each junction it leads to. Count how many
traffic lights end up at each junction.

**Input** (`input.txt`): N and M (0 < N ≤ 100, 0 ≤ M ≤ N(N−1)/2), then M lines with pairs i j — the junctions connected by a tunnel. There are no loops or duplicate tunnels.
**Output** (`output.txt`): N numbers: the k-th one is the number of traffic lights at junction k.

Examples: `7 10 / 5 1 / 3 2 / 7 1 / 5 2 / 7 4 / 6 5 / 6 4 / 7 5 / 2 1 / 5 3` → `3 3 2 2 5 2 3`.
