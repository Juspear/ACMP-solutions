# Colored rain

Hills are connected by bridges and each hill was painted red, blue or green by the rain.
A bridge is bad if it connects hills of different colors. Count the bad bridges.

**Input** (`input.txt`): N (0 < N ≤ 100), the N×N adjacency matrix of bridges, an empty line, then N colors (1 — red, 2 — blue, 3 — green).
**Output** (`output.txt`): the number of bad bridges.

Examples: the 7-hill sample from the statement → `4`.
