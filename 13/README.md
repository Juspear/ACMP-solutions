# Bulls and cows

Petya thinks of a four-digit number with distinct digits, Vasya makes a guess (also with
distinct digits). Bulls are digits that match in value and position, cows are digits
that are present in both numbers but stand in different positions. Given both numbers,
output the number of bulls and cows.

**Input** (`input.txt`): two four-digit numbers A (the secret) and B (the guess).
**Output** (`output.txt`): the number of bulls and the number of cows.

Examples: `5671 7251` → `1 2`, `2034 6234` → `2 1`.
