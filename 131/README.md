# Census

A house has N residents, each described by age V and sex S (1 for male, 0 for female).
Find the index of the oldest male resident; if there are several, take the smallest index,
and if there are no males at all, output -1.

**Input** (`input.txt`): N (N ≤ 100), then N lines with V (1 ≤ V ≤ 100) and S.
**Output** (`output.txt`): the index of the oldest man or -1.

Examples: `4 / 25 1 / 70 1 / 100 0 / 3 1` → `2`, `2 / 25 0 / 25 1` → `2`.
