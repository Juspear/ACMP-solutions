# Fibonacci numbers

The Fibonacci sequence is defined by a₀ = 0, a₁ = 1 and aₖ = aₖ₋₁ + aₖ₋₂ for k > 1.
Find the N-th Fibonacci number.

**Input** (`input.txt`): an integer N (0 ≤ N ≤ 30).
**Output** (`output.txt`): the N-th Fibonacci number.

Examples: `7` → `13`.
