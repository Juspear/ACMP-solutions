# Inverse permutation

A permutation of N elements is given. Find its inverse — the permutation that, composed with
the original one in either order, gives the identity.

**Input** (`input.txt`): N (0 < N ≤ 20000) on the first line, the permutation on the second.
**Output** (`output.txt`): the inverse permutation.

Examples: `3 / 2 3 1` → `3 1 2`.
