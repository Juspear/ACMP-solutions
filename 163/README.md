# Equation for 5th grade

An equation is a string of exactly 5 characters: the second one is `+` or `-`, the fourth
one is `=`. Among the first, third and fifth characters two are digits and one is the
unknown `x`. Solve the equation for x.

**Input** (`input.txt`): one line with the equation.
**Output** (`output.txt`): the integer value of x.

Examples: `x+5=7` → `2`, `3-x=9` → `-6`.
