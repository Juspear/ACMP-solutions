# Lucky ticket 2

A ticket is lucky if it can be cut between two digits into two parts whose numbers have
the same digital root (repeated digit sum until a single digit remains). Decide whether the given
ticket is lucky. The number may start with zeros.

**Input** (`input.txt`): the ticket number, from 1 to 100 digits.
**Output** (`output.txt`): `YES` if the ticket is lucky, otherwise `NO`.

Examples: `0015420` → `YES`, `00100` → `NO`.
