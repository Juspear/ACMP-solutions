# Natural number sequence

All natural numbers are written one after another without separators:
123456789101112131415... Find the position where the decimal notation of a given number N
appears in this string for the first time (positions are numbered from one).

**Input** (`input.txt`): the number N (1 ≤ N ≤ 10^4).
**Output** (`output.txt`): the position of the first occurrence of N.

Examples: `45` → `4`, `101` → `10`, `142` → `73`.
