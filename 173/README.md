# Palindrome number

Find all bases from 2 to 36 in which the representation of a given number N is a
palindrome. Print `unique` if there is exactly one such base, `multiple` if there are several,
or `none` if there are none; in the first two cases also list the bases in increasing order.

**Input** (`input.txt`): a decimal number N (1 ≤ N ≤ 10^9).
**Output** (`output.txt`): `unique`, `multiple` or `none`, followed by a line with the suitable bases if any exist.

Examples: `123` → `unique` / `6`, `111` → `multiple` / `6 10 36`, `102892748` → `none`.
