# Rectangle 2

Three vertices of a rectangle are given in arbitrary order. Find the fourth one.

**Input** (`input.txt`): x1 y1 x2 y2 x3 y3 — integers not exceeding 1000 in absolute value.
**Output** (`output.txt`): the coordinates of the fourth vertex.

Examples: `0 3 0 0 5 0` → `5 3`, `1 4 8 3 7 6` → `2 1`.
