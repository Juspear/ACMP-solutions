# Treasure

A pirate map is a list of instructions, each saying to walk a number of unit steps in one of
eight directions (1 north, 2 north-east, 3 east, 4 south-east, 5 south, 6 south-west,
7 west, 8 north-west). Starting at the origin, with OX pointing east and OY pointing north,
find the point where the treasure is buried.

**Input** (`input.txt`): N (1 ≤ N ≤ 40), then N lines with a direction (1–8) and a step count (1–1000).
**Output** (`output.txt`): the coordinates X and Y of the treasure with three digits after the decimal point.

Examples: `6 / 1 3 / 3 1 / 1 1 / 3 3 / 5 2 / 7 1` → `3.000 2.000`, `1 / 8 10` → `-7.071 7.071`.
