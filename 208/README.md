# Funny game

Take an integer, write it in binary (starting with a one) and keep rotating its digits
cyclically: the last digit moves to the front and the rest shift right. Among all the
sequences obtained this way, take the largest one as a binary number and output it in decimal.

**Input** (`input.txt`): one integer N (0 ≤ N ≤ 32767).
**Output** (`output.txt`): the result of the game.

Examples: `19` → `28`, `1212` → `1938`.
