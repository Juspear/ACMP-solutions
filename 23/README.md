# Fortune telling

Masha tells fortunes with numbers: for a natural number n she needs the sum of all
numbers that divide n without a remainder. Write a program that computes it.

**Input** (`input.txt`): a natural number n (n ≤ 1000).
**Output** (`output.txt`): the sum of all natural divisors of n.

Examples: `6` → `12`, `10` → `18`.
