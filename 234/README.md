# Minesweeper

Given the size of a Minesweeper field and the positions of all mines, build the full map:
every mine cell shows `*`, every other cell shows the number of mines among its up to eight
neighbours, or `.` if there are none.

**Input** (`input.txt`): N, M and K (1 ≤ N, M ≤ 200, 0 ≤ K ≤ N·M), then K lines with the row and column of a mine (1-based).
**Output** (`output.txt`): N lines of M characters each describing the map.

Examples: the 10×9 field with 23 mines from the statement → the corresponding filled map, e.g. its first line is `.111..1*1`.
