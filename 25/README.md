# Greater - less

Given two integers A and B (absolute value up to 2×10^9), compare them and output the
comparison sign.

**Input** (`input.txt`): numbers A and B (on two lines).
**Output** (`output.txt`): `<` if A < B, `>` if A > B, `=` if they are equal.
