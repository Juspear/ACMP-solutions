# Twofold numbers

A natural number is twofold if its decimal notation uses at most two different digits.
Find the twofold number closest to N; if there are two, output the smaller one.

**Input** (`input.txt`): a natural number N ≤ 30000.
**Output** (`output.txt`): the closest twofold number.

Examples: `123` → `122`, `2012` → `2020`, `11111` → `11111`.
