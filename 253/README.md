# Striking clock

An old clock strikes every half hour: at the start of each hour it strikes as many times
as the hour on a 12-hour dial (12 times at noon and midnight), and once at half past.
Given a time interval shorter than 24 hours, count how many strikes happen during it.

**Input** (`input.txt`): the start moment and the end moment, each as hours (0–23) and minutes (1–59, never 30).
**Output** (`output.txt`): the number of strikes.

Examples: `5 20 / 10 25` → `45`, `10 25 / 5 20` → `135`, `5 2 / 5 21` → `0`.
