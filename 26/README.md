# Two circles

Two circles are given on a plane. Check whether they have at least one common point.

**Input** (`input.txt`): two lines, each with the center coordinates x, y
(|x|, |y| ≤ 5000) and the radius r (1 ≤ r ≤ 1000) of one circle.
**Output** (`output.txt`): `YES` if the circles have a common point, otherwise `NO`.

Examples: `0 0 2` / `0 3 2` → `YES`, `1 1 1` / `4 4 1` → `NO`.
