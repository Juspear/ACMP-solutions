# Metro

A circular metro line has N stations numbered 1..N, where station 1 is next to station N.
Vitya travels from station i to station j. Find the smallest number of intermediate
stations he has to pass, going either way around the ring.

**Input** (`input.txt`): three numbers N, i, j (N ≤ 100, i ≠ j).
**Output** (`output.txt`): the minimum number of stations strictly between i and j along the shorter way.

Examples: `100 5 6` → `0`, `10 1 9` → `1`.
