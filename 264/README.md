# Thaw

A thaw is a period of consecutive days on which the average daily temperature is above
zero. Given the temperatures for N days, find the length of the longest thaw.

**Input** (`input.txt`): N (1 ≤ N ≤ 100), then N integer temperatures from -50 to 50.
**Output** (`output.txt`): the maximum number of consecutive days with positive temperature, or 0 if there are none.

Examples: `6` / `-20 30 -40 50 10 -10` → `2`, `8` / `10 20 30 1 -10 1 2 3` → `4`, `5` / `-10 0 -10 0 -10` → `0`.
