# Painter

A white canvas of width w and height h is painted with n axis-parallel rectangles whose
corners have integer coordinates. Find the area of the canvas that remains unpainted.

**Input** (`input.txt`): w and h (1 ≤ w, h ≤ 100), then n (0 ≤ n ≤ 5000), then n lines x1 y1 x2 y2 — the top-left and bottom-right corners of each rectangle (0 ≤ x1 < x2 ≤ w, 0 ≤ y1 < y2 ≤ h).
**Output** (`output.txt`): the unpainted area.

Examples: `5 5 / 2 / 1 1 3 3 / 2 2 4 4` → `18`, `2 1 / 1 / 1 0 2 1` → `1`.
