# Fibonacci numbers 2

The Fibonacci sequence starts with 1, 1 and every next term is the sum of the previous two.
Determine whether a given number belongs to this sequence and, if it does, find its
position (counting from 1).

**Input** (`input.txt`): a natural number from 2 to 1200000000.
**Output** (`output.txt`): `1` and on the second line the position if the number is a Fibonacci number, otherwise `0`.

Examples: `8` → `1` / `6`, `10` → `0`.
