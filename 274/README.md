# Friendly numbers

Two numbers are friendly if they are made of exactly the same set of digits, for example
1132 and 32321. For each pair of numbers, determine whether they are friendly.

**Input** (`input.txt`): K (K ≤ 10), then K lines with two integers A and B (0 ≤ A, B ≤ 10^9).
**Output** (`output.txt`): K lines, `YES` if the pair is friendly and `NO` otherwise.

Examples: `1 / 1132 32321` → `YES`, `2 / 12 123 / 11 111` → `NO YES`.
