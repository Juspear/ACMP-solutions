# Symmetry

A line L parallel to one of the coordinate axes is given by two distinct points on it,
along with a point A. Find the point B that is the mirror image of A with respect to L
(if A lies on L, then B = A).

**Input** (`input.txt`): first line x1, y1, x2, y2 - two points of L; second line xA, yA. All values are integers with absolute value up to 10^8.
**Output** (`output.txt`): the coordinates xB and yB.

Examples: `0 0 0 1` / `10 10` → `-10 10`, `0 0 1 0` / `10 10` → `10 -10`.
