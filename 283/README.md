# Rune words

A rune is written with two, three or four English letters, where the first letter is
uppercase and the rest are lowercase. A rune word is a sequence of runes written one
after another. Check whether the given word is a rune word.

**Input** (`input.txt`): a non-empty word of English letters, up to 100000 characters long.
**Output** (`output.txt`): `Yes` if the word is a rune word, `No` otherwise.

Examples: `IoIsTheBest` → `Yes`, `IoItIsWaste` → `No`.
