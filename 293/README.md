# Taxes

There are N companies; company i earns V[i] per year and pays a tax of p[i] percent.
Find the company that brings the largest amount of tax to the treasury. If several
companies tie, choose the one with the smallest number.

**Input** (`input.txt`): N, then N profits V[i], then N tax rates p[i].
**Output** (`output.txt`): the number of the company paying the most tax.

Examples: `2 / 1 2 / 3 2` → `2`, `3 / 100 1 50 / 0 100 3` → `3`.
