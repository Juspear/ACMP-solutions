# Fox Alice and cat Basilio

Alice owns only 3-ruble coins and Basilio owns only 5-ruble coins. They pay a price of N
rubles together, exactly and with the minimum total number of coins. Find how many coins
each of them gives.

**Input** (`input.txt`): a natural number N (7 < N < 1000).
**Output** (`output.txt`): the number of Basilio's 5-ruble coins and the number of Alice's 3-ruble coins.

Examples: `8` → `1 1`, `11` → `1 2`, `15` → `3 0`.
