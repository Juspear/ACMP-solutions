# Circles

A puzzle once circulated online: 157892 = 3, 203516 = 2, 409578 = 4, 236271 = ?
The answer is the total number of closed loops ("circles") drawn in the digits of the
number: 0, 6 and 9 have one loop each, 8 has two. Count the loops in a given number.

**Input** (`input.txt`): an integer N (0 ≤ N ≤ 10^100).
**Output** (`output.txt`): the number of loops in the digits of N.

Examples: `157892` → `3`, `203516` → `2`, `409578` → `4`, `236271` → `1`.
