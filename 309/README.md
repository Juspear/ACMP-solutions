# K-amazing numbers

The reverse of a number is the number written with its digits in the opposite order
(the reverse of 7800 is 87). A number is K-amazing if the sum of the number and its
reverse equals K. Count the K-amazing numbers for the given K.

**Input** (`input.txt`): a natural number K (1 ≤ K ≤ 10^6).
**Output** (`output.txt`): the number of K-amazing numbers.

Examples: `222` → `2`, `1050` → `9`.
