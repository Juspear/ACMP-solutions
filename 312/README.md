# Arithmetic progression

The first two members of an arithmetic progression are known. Find the member of the
progression with the given index N.

**Input** (`input.txt`): three integers A1, A2 and N (1 ≤ A1, A2, N ≤ 1000).
**Output** (`output.txt`): the N-th member of the progression.

Examples: `1 5 3` → `9`.
