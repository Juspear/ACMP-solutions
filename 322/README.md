# Word

Fibonacci numbers start with two ones, and every next one is the sum of the two previous ones.
Characters of a text are numbered from one. Build a word from the characters whose positions are
Fibonacci numbers, keeping their order (each position is taken once).

**Input** (`input.txt`): a string of 1 to 30000 lowercase English letters.
**Output** (`output.txt`): the resulting word.

Examples: `a` → `a`, `abc` → `abc`, `abcdefghij` → `abceh`.
