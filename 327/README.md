# One step from happiness

A tram ticket has a six-digit number, and it is lucky when the sum of its first three digits
equals the sum of its last three. Vova got a ticket whose two sums differ by exactly one and
claims that either the previous or the next ticket is surely lucky. For each ticket, check
whether he is right.

**Input** (`input.txt`): the number of tests K (K ≤ 10), then K six-digit ticket numbers
(leading zeros possible), one per line.
**Output** (`output.txt`): K lines, `Yes` if the previous or the next ticket is lucky, `No` otherwise.

Examples: `3 / 715068 / 445219 / 012200` → `Yes / No / Yes`.
