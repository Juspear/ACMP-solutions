# Dots on dominoes

A domino set contains every unordered pair of halves, where each half has from 0 to N
dots and no tile is repeated (2-5 and 5-2 are the same tile). Find the total number of
dots on all tiles of the set.

**Input** (`input.txt`): a natural number N (N ≤ 10000).
**Output** (`output.txt`): the total number of dots.

Examples: `2` → `12`.
