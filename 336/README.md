# Elevator

An experimental elevator has only two buttons: `1` moves it one floor up and `2` moves it one
floor down. Dilly rides it until he has visited every floor at least once. Given the sequence of
pressed buttons, find the number of floors in the house. The elevator never went below the first
or above the last floor.

**Input** (`input.txt`): a string of 1 to 100 characters `1` and `2` without spaces.
**Output** (`output.txt`): the number of floors.

Examples: `11` → `3`, `21212` → `2`, `1221221221221` → `6`.
