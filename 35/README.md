# Finite automata

A professor found descriptions of k finite automata. He rates how interesting an automaton
with n states and m transitions is by the value d = 19m + (n + 239)(n + 366) / 2.
Compute this value for every automaton.

**Input** (`input.txt`): the number k (1 ≤ k ≤ 10000), then k lines with n and m (0 ≤ n ≤ 1000, 0 ≤ m ≤ 26n²).
**Output** (`output.txt`): k lines, the i-th containing the value d for the i-th automaton.

Examples: `2 0` → `44344`, `15 20` → `48767`, `1000 26000` → `1340237`.
