# Divisibility by 11

Check whether a given natural number is divisible by 11. A number is divisible by 11 exactly
when the difference between the sum of its digits on even positions and the sum of its digits
on odd positions is divisible by 11. The number can have up to 10001 digits.

**Input** (`input.txt`): a natural number N (1 ≤ N ≤ 10^10000).
**Output** (`output.txt`): `YES` if N is divisible by 11, otherwise `NO`.

Examples: `121` → `YES`, `1211` → `NO`.
