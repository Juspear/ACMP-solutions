# Permutation shift

A cyclic shift by k of a permutation p1, ..., pn is pk+1, ..., pn, p1, ..., pk (the
permutation itself is also a shift). Find the lexicographically smallest cyclic shift of
the given permutation.

**Input** (`input.txt`): the order n (1 ≤ n ≤ 10^5), then the permutation p1, ..., pn.
**Output** (`output.txt`): the lexicographically smallest cyclic shift.

Examples: `3` / `3 2 1` → `1 3 2`.
