# Counting sort

Temperatures were measured at N points of a planet and rounded to integers between −100 and
100. Sort them in non-decreasing order. Since N can be up to a million and the value range
is tiny, counting sort is the natural approach.

**Input** (`input.txt`): N (N ≤ 10^6) on the first line, then N integers with absolute value at most 100.
**Output** (`output.txt`): the temperatures in non-decreasing order separated by spaces.

Examples: `3 / 9 -20 14` → `-20 9 14`, `10 / 12 7 92 5 18 4 32 48 11 74` → `4 5 7 11 12 18 32 48 74 92`.
