# Chess knight

Given the square of a knight on a standard chessboard (files a–h, ranks 1–8), list all
squares the knight can reach in one move.

**Input** (`input.txt`): two characters, the knight's square.
**Output** (`output.txt`): all reachable squares, one per line, in any order.

Examples: `e2` → `c1 c3 d4 f4 g1 g3`, `a1` → `b3 c2`.
