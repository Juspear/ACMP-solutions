# Zeros

Find the length of the longest contiguous run of zeros in a string of zeros and ones.

**Input** (`input.txt`): a single string of 0s and 1s without spaces, length from 1 to 100.
**Output** (`output.txt`): the length of the longest run of zeros.

Examples: `00101110000110` → `4`.
