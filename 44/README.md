# Arrows

A string consists only of the characters `>`, `<` and `-`. Arrows are the substrings
`>>-->` and `<--<<`. Count how many arrows are hidden in the string (arrows may overlap).

**Input** (`input.txt`): a string of `>`, `<` and `-` without spaces, at most 250 characters long.
**Output** (`output.txt`): the number of arrows.

Examples: `<<<<>>--><--<<--<<>>>--><<<<<` → `4`.
