# Biathlon

There are five round targets of radius 10 with centers at (0, 0), (25, 0), (50, 0),
(75, 0) and (100, 0). Given the points hit by five bullets, count how many targets were
hit at least once (a point on the edge counts as a hit).

**Input** (`input.txt`): five lines, each with integer coordinates x and y of a bullet hole (|x|, |y| ≤ 1000).
**Output** (`output.txt`): the number of targets hit.

Examples: `0 0`, `25 0`, `50 0`, `75 0`, `100 0` → `5`; `0 0`, `0 0`, `0 0`, `75 0`, `100 0` → `3`.
