# Number E

Print the number E rounded to n digits after the decimal point. For this problem E is
taken to be exactly 2.7182818284590452353602875.

**Input** (`input.txt`): an integer n (0 ≤ n ≤ 25).
**Output** (`output.txt`): E rounded to n decimal places.

Examples: `0` → `3`, `25` → `2.7182818284590452353602875`, `13` → `2.7182818284590`.
