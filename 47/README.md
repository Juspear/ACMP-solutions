# Best divisor

A number a is better than b if its digit sum is larger, or, when the digit sums are equal,
if a is smaller. Among all divisors of n (including 1 and n itself) find the best one.

**Input** (`input.txt`): an integer n (1 ≤ n ≤ 10^5).
**Output** (`output.txt`): the best divisor of n.

Examples: `10` → `5`, `239` → `239`.
