# The worst divisor

A number a is better than b if its digit sum is larger, or, with equal digit sums, if a is
smaller. Given n, find its divisor d such that every other divisor of n is better than d.

**Input** (`input.txt`): an integer n (1 ≤ n ≤ 10^5000).
**Output** (`output.txt`): the worst divisor of n.

Examples: `10` → `10`, `239` → `1`.
