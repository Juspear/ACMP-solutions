# Short sequence

Build the sequence S1S2S3..., where the group Sk is the numbers from 1 to k written one
after another: 1 12 123 1234 ... 12345678910 and so on. Find the digit at position N of
this sequence.

**Input** (`input.txt`): an integer N (0 < N < 32768).
**Output** (`output.txt`): the digit standing at position N.

Examples: `3` → `2`, `20` → `5`.
