# Battleship 2

An N × M battleship field is given where `*` marks cells occupied by ships and `.` marks free
cells. One more single-cell ship has to be placed into a free cell such that none of its
side-adjacent cells is occupied. Count the number of cells where it can be placed.

**Input** (`input.txt`): N and M (1 ≤ N, M ≤ 100), then N lines of M characters describing the field.
**Output** (`output.txt`): the number of possible positions.

Examples: `4 4 / **** / **.. / *... / *...` → `4`, `4 3 / *** / ... / ... / ***` → `0`.
