# Blueberry picking

N blueberry bushes grow in a circle, so every bush has exactly two neighbours, and the i-th
bush carries a_i berries. A picking module standing in front of a bush collects the berries
from that bush and both of its neighbours. Find the maximum number of berries the module can
collect in one pass.

**Input** (`input.txt`): N (3 ≤ N ≤ 1000) on the first line, then N positive integers a_1 … a_N (each ≤ 1000).
**Output** (`output.txt`): the maximum number of berries.

Examples: `4 / 1 2 3 4` → `9`, `3 / 1 2 3` → `6`.
