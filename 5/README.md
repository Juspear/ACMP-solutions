# Statistics

Vasya got a 3 on odd days of the month and a 4 on even days. Given the list of days,
print the odd days on the first line and the even days on the second line, keeping the
input order. On the third line print `YES` if there are at least as many 4s as 3s,
otherwise `NO`.

**Input** (`input.txt`): N (1 ≤ N ≤ 100) on the first line, then N numbers from 1 to 31.
**Output** (`output.txt`): odd days, even days, and `YES`/`NO` on three lines.

Example: `5` / `4 16 19 31 2` → `19 31` / `4 16 2` / `YES`.
