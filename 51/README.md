# Factorials!!!

A multi-factorial with k exclamation marks is the product n·(n−k)·(n−2k)·… taken while the
factors stay positive. Given n and a string of k exclamation marks, compute its value.

**Input** (`input.txt`): an integer n (1 ≤ n ≤ 10), a space and k exclamation marks (1 ≤ k ≤ 20).
**Output** (`output.txt`): the value of the multi-factorial.

Examples: `10 !!!` → `280`, `9 !!` → `945`, `3 !` → `6`.
