# Staircase

Petya builds a staircase out of cubes: a row of towers standing next to each other, where
each tower is exactly one cube taller than the previous one (the first tower has one cube).
Given the number of cubes K, find the height of the last step of the tallest staircase
that can be built from them.

**Input** (`input.txt`): the number of cubes K (1 ≤ K ≤ 10^6).
**Output** (`output.txt`): the number of cubes in the last step of the tallest possible staircase.

Examples: `1` → `1`, `4` → `2`, `6` → `3`.
