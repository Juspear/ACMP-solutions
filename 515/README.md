# Traps

A walker leaves home at the origin, visits N traps in the given order and returns home.
Find the total distance travelled.

**Input** (`input.txt`): N (N ≤ 10), then N lines with integer coordinates X Y of the traps (-10 ≤ X, Y ≤ 10).
**Output** (`output.txt`): the total distance with three digits after the decimal point.

Examples: `1` / `1 0` → `2.000`, `2` / `1 0` / `1 1` → `3.414`, `3` / `1 0` / `1 1` / `0 1` → `4.000`.
