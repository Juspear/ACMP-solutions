# Smallest and largest numbers from the same digits

Given a natural number N, rearrange its digits to build the smallest and the largest
numbers possible. The smallest number must not start with a zero.

**Input** (`input.txt`): a natural number N (N ≤ 2·10^9).
**Output** (`output.txt`): the smallest and the largest numbers on one line, separated by a space.

Examples: `7051` → `1057 7510`, `851` → `158 851`.
