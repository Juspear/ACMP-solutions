# Lucky ticket

A six-digit ticket number is called lucky if the sum of its first three digits equals the
sum of its last three digits. Check whether the given ticket is lucky.

**Input** (`input.txt`): six decimal digits without spaces.
**Output** (`output.txt`): `YES` if the ticket is lucky, `NO` otherwise.

Examples: `385916` → `YES`, `123456` → `NO`.
