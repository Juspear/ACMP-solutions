# Old lady Shapoklyak's solitaire

There are decks with p, p+1, ..., k cards. In one move the old lady takes a deck: if it has an
even number of cards she halves it, otherwise she triples it and adds one more card. A deck with
exactly two cards is never touched again. The solitaire succeeds when every deck has two cards.
Determine whether it succeeds and, if so, the total number of moves.

**Input** (`input.txt`): two numbers p and k (2 ≤ p < k < 1000).
**Output** (`output.txt`): the number of moves, or 0 if the solitaire never succeeds.

Examples: `2 3` → `6`, `5 8` → `28`.
