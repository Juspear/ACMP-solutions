# Similar arrays

Two arrays are called similar if the sets of values occurring in them are the same.
Determine whether two given arrays are similar.

**Input** (`input.txt`): lengths M and N (1 ≤ M, N ≤ 16000), then the M elements of the first
array and the N elements of the second one (integers with absolute value at most 32000).
**Output** (`output.txt`): 1 if the arrays are similar, otherwise 0.

Examples: `4 3 / 1 2 3 2 / 1 2 3` → `1`, `2 3 / 1 2 / 2 3 1` → `0`.
