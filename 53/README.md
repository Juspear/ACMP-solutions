# Coloring the multiplication table

An n×m multiplication table holds i·j in row i, column j. All numbers start black, then
even numbers are painted red, multiples of 3 are repainted green, and multiples of 5 are
repainted blue. Count how many numbers end up in each color.

**Input** (`input.txt`): two natural numbers n and m (1 ≤ n, m ≤ 1000).
**Output** (`output.txt`): four lines `RED : r`, `GREEN : g`, `BLUE : b`, `BLACK : k`.

Examples: `10 10` → `RED : 21`, `GREEN : 39`, `BLUE : 36`, `BLACK : 4`.
