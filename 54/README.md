# Game theory

For a payoff matrix K of a matrix game, the lower value is the maximum over rows of the row
minimum, and the upper value is the minimum over columns of the column maximum. Find both.

**Input** (`input.txt`): n and m (1 ≤ n, m ≤ 100), then the n×m matrix; elements do not exceed 1000 in absolute value.
**Output** (`output.txt`): the lower and upper values separated by a space.

Examples: `3 3 / 4 -1 -3 / -2 1 3 / 0 2 -3` → `-2 2`.
