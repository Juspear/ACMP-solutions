# Bit reverse

Write a positive integer m in binary, reverse the order of its digits and convert the result
back to decimal. This value is B(m). Compute B(m) for a given m.

**Input** (`input.txt`): a natural number m (m ≤ 10^9).
**Output** (`output.txt`): the value B(m).

Examples: `4` → `1`, `6` → `3`.
