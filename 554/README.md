# Pizza

Find the maximum number of pieces (not necessarily equal) into which a round pizza can be cut
with N straight cuts.

**Input** (`input.txt`): the number of cuts N (N ≤ 1000).
**Output** (`output.txt`): the maximum number of pieces.

Examples: `2` → `4`, `3` → `7`.
