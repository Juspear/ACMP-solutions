# Fortune telling 2

For a positive integer N count how many positive integers smaller than N are coprime with N
(their greatest common divisor with N equals 1).

**Input** (`input.txt`): a positive integer N (1 ≤ N ≤ 10^5).
**Output** (`output.txt`): the count of numbers less than N that are coprime with N.

Examples: `13` → `12`, `6` → `2`.
