# Multiplication table

Imagine an N × M multiplication table where the cell in row i and column j holds i·j. Count
how many times each digit from 0 to 9 appears when all numbers of the table are written out.

**Input** (`input.txt`): two integers N and M (1 ≤ N, M ≤ 1000).
**Output** (`output.txt`): ten lines, the i-th line contains how many times digit i − 1 is written.

Examples: `10 10` → `28 24 27 15 23 15 17 8 15 6` (one number per line).
