# Absolute value of a sum

Given a sequence of integers, choose a subsequence whose sum has the largest possible
absolute value.

**Input** (`input.txt`): n (1 ≤ n ≤ 10000), then n integers with absolute value at most 10000.
**Output** (`output.txt`): the length k of the chosen subsequence, then k distinct indices of
its elements.

Examples: `5 / -1 4 -1 6 -7` → `2 / 2 4`.
