# Nice table check

A table of zeros and ones is called nice if it contains no 2×2 square filled entirely with
zeros or entirely with ones. For each of several given tables, decide whether it is nice.

**Input** (`input.txt`): the number of tests t (1 ≤ t ≤ 10); each test is n and m (1 ≤ n, m ≤ 100) followed by n rows of m values 0 or 1.
**Output** (`output.txt`): for each test a line `YES` if the table is nice and `NO` otherwise.

Examples: tables `1×1 [0]`, a 4×4 table without uniform 2×2 squares and a 3×3 table with a corner of zeros → `YES`, `YES`, `NO`.
