# Simple calculation

Convert a natural number n into base k and output the difference between the product and
the sum of its digits in that base. For instance, 239 in base 8 is 357, giving 3·5·7 − (3+5+7) = 90.

**Input** (`input.txt`): two natural numbers n and k (1 ≤ n ≤ 10^9, 2 ≤ k ≤ 10), written in decimal.
**Output** (`output.txt`): the product of the digits minus their sum, in decimal.

Examples: `239 8` → `90`, `1000000000 7` → `-34`.
