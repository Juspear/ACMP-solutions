# Chess

Check a knight move written as `C7-D5`. If the string is not two valid board squares
(letters A–H, digits 1–8) separated by a dash, it is an error. Otherwise decide whether a
knight can make that move.

**Input** (`input.txt`): a non-empty string of at most 5 characters.
**Output** (`output.txt`): `YES` for a valid knight move, `NO` for a well-formed but impossible move, `ERROR` otherwise.

Examples: `C7-D5` → `YES`, `E2-E4` → `NO`, `BSN` → `ERROR`.
