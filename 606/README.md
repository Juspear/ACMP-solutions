# Triangle - 3

Given three segment lengths, check whether they can form a non-degenerate triangle.

**Input** (`input.txt`): three positive integers X, Y, Z (each at most 1000).
**Output** (`output.txt`): `YES` if a triangle can be formed, otherwise `NO`.

Examples: `3 4 5` → `YES`, `1 1 5` → `NO`.
