# Cells

A chessboard is 8×8, columns are labeled A to H and rows 1 to 8, and the cell A1 is black.
Given the coordinate of a cell, determine its color.

**Input** (`input.txt`): a cell coordinate: a letter and a digit, e.g. `C3`.
**Output** (`output.txt`): `WHITE` or `BLACK`.

Examples: `C3` → `BLACK`, `G8` → `WHITE`.
