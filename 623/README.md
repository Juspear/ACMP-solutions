# Fibonacci again

Fibonacci numbers are defined by F0 = F1 = 1 and Fn = Fn-1 + Fn-2. Find the last digit
of the n-th Fibonacci number.

**Input** (`input.txt`): an integer n (0 ≤ n ≤ 10^8).
**Output** (`output.txt`): the last digit of Fn.

Examples: `1` → `1`, `5` → `8`.
