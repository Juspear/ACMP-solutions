# ACM World Finals

Build the full name of a team from its short name and the surnames of its three members:
the team name, a colon, then the surnames sorted alphabetically and separated by commas.
Exactly one space follows every punctuation mark.

**Input** (`input.txt`): four lines — the team name and three surnames (1 to 50 characters,
English letters and spaces).
**Output** (`output.txt`): one line with the full team name.

Examples: `Dream Team / Knuth / Dijkstra / Cormen` → `Dream Team: Cormen, Dijkstra, Knuth`,
`Team / a / A / B` → `Team: A, B, a`.
