# NEERC

n universities sent applications, the i-th one wants to send a_i teams. The contest is held
in k halls, and each hall may contain at most one team from the same university. Find the
largest number of teams that can be admitted.

**Input** (`input.txt`): n, then n numbers a_1..a_n, then k (all positive, up to 10000).
**Output** (`output.txt`): the maximum number of admitted teams.

Examples: `3 / 1 2 4 / 3` → `6`, `3 / 1 2 4 / 4` → `7`.
