# Prime row

All primes are written in increasing order without separators: 23571113171923...
For each requested position (numbered from one) output the digit standing there.

**Input** (`input.txt`): M (1 ≤ M ≤ 1000), then M positions, each from 1 to 10000.
**Output** (`output.txt`): M digits in one line without spaces.

Examples: `3 / 1 4 11` → `271`, `5 / 2 5 6 8 12` → `31139`.
