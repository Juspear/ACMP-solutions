# Strange lottery

The prize is determined by a number N printed on the ticket: each of the two owners crosses
out exactly one digit, and the remaining number is the prize. Find the largest number that
can be obtained from N by deleting exactly two digits.

**Input** (`input.txt`): a number N (100 ≤ N < 10^250) without leading zeros.
**Output** (`output.txt`): the maximum value obtainable by deleting two digits.

Examples: `102` → `2`, `995051` → `9955`.
