# Hamming distance

A binary message s was received; it was one of n candidate messages of the same length sent
over a noisy channel. Find all candidates with the minimum Hamming distance to s (the number of
positions where the strings differ).

**Input** (`input.txt`): s, then n, then n binary strings of the same length as s.
**Output** (`output.txt`): the number k of messages with the minimum distance, then their indices in increasing order.

Examples: `010101 / 3 / 110011 / 011001 / 000111` → `2 / 2 3`.
