# Keyboard

Given a lowercase English letter, output the letter located to its right on a standard
QWERTY keyboard. The keyboard wraps around: after `p` comes `a`, after `l` comes `z`, and
after `m` comes `q`.

**Input** (`input.txt`): a single lowercase English letter.
**Output** (`output.txt`): the letter to the right of it.

Examples: `q` → `w`, `p` → `a`, `l` → `z`, `m` → `q`.
