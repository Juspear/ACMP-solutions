# Palindromic time

A baker wants to take a cake out of the oven at a moment when the clock shows a
"palindromic" time, i.e. one that reads the same in both directions. Given the time the
cake was put in, find the nearest palindromic time strictly after it (the clock wraps
around after 23:59).

**Input** (`input.txt`): a time in the format HH:MM (00 ≤ HH ≤ 23, 00 ≤ MM ≤ 59).
**Output** (`output.txt`): the nearest palindromic time in the format HH:MM.

Examples: `00:00` → `01:10`, `12:34` → `13:31`, `23:59` → `00:00`.
