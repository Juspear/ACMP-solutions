# Bus numbers

A valid registration number consists of a letter, three digits and two more letters, where
only the letters A, B, C, E, H, K, M, O, P, T, X, Y are allowed. Check each of the N
recorded strings against this format.

**Input** (`input.txt`): N (N ≤ 50), then N strings of length 1 to 300 without spaces.
**Output** (`output.txt`): for each string `Yes` if it is a valid number, otherwise `No`.

Examples: `P204BT` → `Yes`, `X182YZ` → `No`, `a216bc` → `No`, `A216BC` → `Yes`, `ABC216` → `No`.
