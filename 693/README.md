# Permutation

Check whether one name can be obtained from another by rearranging its letters, ignoring
letter case.

**Input** (`input.txt`): two words of English letters separated by a single space, each 1 to 50 characters long.
**Output** (`output.txt`): `Yes` if one word is an anagram of the other, `No` otherwise.

Examples: `TomMarvoloRiddle IamLordVoldemort` → `Yes`, `stop pots` → `Yes`, `abbc bac` → `No`.
