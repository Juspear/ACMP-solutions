# Lazy student

A student has to pass N subjects. Each teacher is available every day on some segment of
days [A, B] of the month. Determine whether there is a single day when all the teachers
are available at once.

**Input** (`input.txt`): N (N ≤ 100), then N lines with A and B (1 ≤ A ≤ B ≤ 31).
**Output** (`output.txt`): `YES` if such a day exists, `NO` otherwise.

Examples: `1 / 1 2` → `YES`, `2 / 1 2 / 3 4` → `NO`, `3 / 1 8 / 3 5 / 4 9` → `YES`.
