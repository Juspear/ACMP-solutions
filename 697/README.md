# Renovation

An office is L meters long, W meters wide and H meters high. Only the four walls need
painting (doors and windows are ignored), and one can of paint covers 16 square meters.
Find the minimum number of cans required.

**Input** (`input.txt`): three positive integers L, W, H (each at most 1000).
**Output** (`output.txt`): the minimum number of paint cans.

Examples: `8 8 2` → `4`, `1 1 3` → `1`.
