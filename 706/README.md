# Cannon

A cannon at the origin shoots ping-pong balls. An infinite wall runs parallel to the X axis at
distance R, and a target point (X, Y) lies between the axis and the wall. The ball must bounce
off the wall once and then hit the target. Find the distance from the Y axis to the point
where the ball hits the wall.

**Input** (`input.txt`): integers R, X, Y (-10 ≤ X ≤ 10, 0 ≤ Y < R ≤ 10).
**Output** (`output.txt`): the distance with at least two digits after the decimal point.

Examples: `10 5 5` → `3.33`, `10 10 5` → `6.67`.
