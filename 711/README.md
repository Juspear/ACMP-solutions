# Karting race

n drivers each wrote down their lap times for m laps. The winner is the driver with the
smallest total time. Print the name of the winner (any one if there is a tie).

**Input** (`input.txt`): n and m (1 ≤ n, m ≤ 100), then for every driver a line with the name and a line with m lap times.
**Output** (`output.txt`): the name of the winner.

Examples: `5 3 / Sumaher / 2 1 1 / Barikelo / 2 1 2 / Olonso / 1 2 1 / Vasya / 1 1 1 / Fedya / 1 1 1` → `Vasya`.
