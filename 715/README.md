# Misha and the negative

A binary picture of n×m pixels (B and W) is given together with the "negative" produced by
Misha's buggy program. In a correct negative every pixel is inverted. Count the pixels of the
negative that are wrong.

**Input** (`input.txt`): n and m (1 ≤ n, m ≤ 100), n rows of the original picture, an empty line, then n rows of the negative.
**Output** (`output.txt`): the number of incorrect pixels.

Examples: `2 2 / BW / BB / (empty) / WW / BW` → `2`.
