# Ali Baba

There are N items in the cave, each with a value that may be negative. Ali Baba can carry
at most M of them. Find the maximum total value he can take away.

**Input** (`input.txt`): N and M (1 ≤ N ≤ 1000, 0 ≤ M ≤ N), then N integers in the range [-1000, 1000].
**Output** (`output.txt`): the maximum possible total value.

Examples: `4 2 / 2 3 1 4` → `7`, `4 2 / 0 3 -1 -2` → `3`.
