# Transport

A car drives along a straight road from point 0 to point L at maximum speed V km/h.
There are N traffic inspectors standing at different points of the road, and each one
stops every passing car for a given number of minutes. Find the minimum time needed to
cover the road.

**Input** (`input.txt`): N, V and L (0 ≤ N ≤ 30, 1 ≤ V, L ≤ 200), then N pairs: the position of an inspector and the stop time in minutes.
**Output** (`output.txt`): the total time in minutes with exactly two digits after the decimal point.

Examples: `3 60 45 / 0 5 25 5 40 5` → `60.00`, `2 78 150 / 2 10 78 1` → `126.38`.
