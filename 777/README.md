# Alarm clock

An explorer goes to sleep at hour S and sets his alarm for hour T. The alarm clock has a
12-hour dial, so it always rings in less than 12 hours. Find how many hours pass before it rings.

**Input** (`input.txt`): two integers S and T (1 ≤ S, T ≤ 12, S ≠ T).
**Output** (`output.txt`): the number of hours until the alarm rings.

Examples: `10 12` → `2`.
