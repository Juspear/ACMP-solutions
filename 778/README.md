# Office

For each of the 31 days of a month we know how many employees came to the office. Every
employee takes exactly 4 days off per month. Find the total number of employees.

**Input** (`input.txt`): 31 non-negative integers, the attendance for each day.
**Output** (`output.txt`): the number of employees.

Examples: `10` repeated 27 times followed by four `0` → `10`.
