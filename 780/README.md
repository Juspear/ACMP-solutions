# Football

After every goal Vasya wrote down the score shown on the board, for example
1:0, 1:1, 1:2, 2:2, 2:3, and then added up all the numbers he wrote. Given this sum,
determine how many goals were scored in the match.

**Input** (`input.txt`): a non-negative integer not exceeding 1000, the sum Vasya got.
**Output** (`output.txt`): the total number of goals.

Examples: `15` → `5`.
