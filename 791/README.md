# Neighbouring cells

The cells of a chessboard are numbered 1 to 64 row by row, left to right and bottom to top.
Given a cell number, list all cells sharing a side with it.

**Input** (`input.txt`): one integer from 1 to 64.
**Output** (`output.txt`): the numbers of the adjacent cells in increasing order, separated by spaces.

Examples: `2` → `1 3 10`, `64` → `56 63`.
