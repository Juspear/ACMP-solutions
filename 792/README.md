# Trade deals in Amber

Each trader has an age N and comes from a country using base P. His coefficient is the sum
of digits of N written in base P. The guild earns the coefficient of a trader only when the
coefficients of the two traders are equal, otherwise it earns nothing. Find the guild's profit.

**Input** (`input.txt`): N1 P1 on the first line, N2 P2 on the second (0 ≤ N ≤ 2147483647, 2 ≤ P ≤ 16).
**Output** (`output.txt`): the guild's profit.

Examples: `7 2 / 9 4` → `3`, `5 8 / 5 2` → `0`, `31 16 / 400 9` → `16`.
