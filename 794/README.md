# Role-playing game

Each of n players gets a level from 1 to m, shown with badges: a white badge is worth 1 level,
a red one is worth k levels, and a player may hold at most k - 1 white badges. Levels aren't
known in advance, so find the minimum total number of badges to prepare so that any
combination of levels can be shown.

**Input** (`input.txt`): n, m, k (1 ≤ n ≤ 10^4, 1 ≤ m ≤ 10^5, 1 ≤ k ≤ 10^5).
**Output** (`output.txt`): the minimum number of badges.

Examples: `3 4 2` → `9`.
