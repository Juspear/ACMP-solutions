# Chessboard - 2

An m×n board is painted in a chessboard pattern. We know the color of the cell in row i,
column j. Decide which color occurs more often on the board.

**Input** (`input.txt`): five integers m, n, i, j, c (1 ≤ m, n ≤ 10^9, c = 0 means black, c = 1 means white).
**Output** (`output.txt`): `black`, `white` or `equal`.

Examples: `3 5 1 1 0` → `black`, `3 5 2 1 0` → `white`, `4 4 1 1 1` → `equal`.
