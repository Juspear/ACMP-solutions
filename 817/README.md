# Manhattan streets

There are n avenues and m streets, each one d meters wide and k meters long; every avenue
crosses every street exactly once. Compute the total asphalt area, counting each crossing
only once.

**Input** (`input.txt`): four integers n, m, d, k (1 ≤ n, m, d, k ≤ 10^9, k > m·d, k > n·d).
**Output** (`output.txt`): the total area in square meters.

Examples: `1 1 5 10` → `75`, `100 10 23 4560` → `11007800`.
