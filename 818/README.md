# Boiling tea

There is a single wall socket and N power strips, the i-th one having a_i outlets.
Strips can be plugged into each other, and every free outlet can power one kettle.
Find the maximum number of kettles that can be boiled at once.

**Input** (`input.txt`): N (1 ≤ N ≤ 10^5), then N integers a_i (1 ≤ a_i ≤ 1000).
**Output** (`output.txt`): the maximum number of kettles.

Examples: `1 / 1` → `1`, `3 / 2 5 4` → `9`.
