# Triangle area

Given integer coordinates of the three vertices of a triangle, compute its exact area.

**Input** (`input.txt`): six integers x1, y1, x2, y2, x3, y3, each at most 10^6 in absolute value.
**Output** (`output.txt`): the exact area of the triangle.

Examples: `2 1 2 4 6 1` → `6`, `0 0 0 3 3 0` → `4.5`.
