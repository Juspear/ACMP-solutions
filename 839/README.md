# Everyone knows

Pasha surveyed people and recorded 1 for everyone who knew a certain fact and 0 for
those who did not. Given the resulting string of zeros and ones, determine whether
everybody knew the fact.

**Input** (`input.txt`): a non-empty string of 0s and 1s, length up to 10^4.
**Output** (`output.txt`): `YES` if there are no zeros, otherwise `NO`.

Examples: `11111101010011` → `NO`, `11` → `YES`.
