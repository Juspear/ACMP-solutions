# Convex hull

Some cells of a grid are black. Paint the minimum number of extra cells so that the set of
black cells becomes convex as a geometric figure, and print the resulting picture.

**Input** (`input.txt`): N and M (1 ≤ N, M ≤ 100), then N lines of M characters `*` (black) or `.` (white).
**Output** (`output.txt`): N lines of M characters — the resulting convex picture.

Examples: `2 4 / ..*. / .**.` → `.**. / .**.`.
