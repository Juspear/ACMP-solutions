# Exams

N applicants came to take two exams, maths and physics. M of them passed maths, F passed
physics and L failed both. Find how many passed both exams, how many passed only maths
and how many passed only physics.

**Input** (`input.txt`): four integers N, M, F and L.
**Output** (`output.txt`): three numbers — passed both, only maths, only physics.

Examples: `2 2 1 0` → `1 1 0`, `10 5 5 5` → `5 0 0`, `10 5 5 0` → `0 5 5`.
