# Fields

Given the integer sides a and b of a rectangular field, determine whether there is a square
field with an integer side and exactly the same area.

**Input** (`input.txt`): two integers a and b.
**Output** (`output.txt`): the side of such a square, or 0 if it does not exist.

Examples: `1 4` → `2`, `2 8` → `4`, `15 42` → `0`.
