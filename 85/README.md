# Repunit GCD

Two numbers are written using only the digit 1: the first has N ones, the second has M
ones. Find their greatest common divisor.

**Input** (`input.txt`): two integers N and M (1 ≤ N, M ≤ 2000).
**Output** (`output.txt`): the GCD without leading zeros.

Examples: `1 1` → `1`, `1 2` → `1`.
