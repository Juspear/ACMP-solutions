# Herons

Each heron in an enclosure stands either on one leg or on two. Petya counted a visible
legs, a bit later Masha counted b (herons may have changed their pose in between).
Find the minimum and maximum possible number of herons.

**Input** (`input.txt`): two integers a and b (1 ≤ a, b ≤ 10^9).
**Output** (`output.txt`): the minimum and the maximum number of herons.

Examples: `3 4` → `2 3`.
