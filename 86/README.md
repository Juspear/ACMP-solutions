# Queens puzzle

Place as many queens as possible on an N×N board so that at least one cell remains
not attacked by any queen. Output that maximum number.

**Input** (`input.txt`): a natural number N (1 ≤ N ≤ 100).
**Output** (`output.txt`): the maximum number of queens.

Examples: `3` → `2`.
