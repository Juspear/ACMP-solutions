# Sudoku

A sudoku of size n is an n²×n² square split into n² blocks of size n×n. It is correct if every
row, every column and every block contains all numbers from 1 to n². Check whether the given sudoku
is correct.

**Input** (`input.txt`): n (1 ≤ n ≤ 10), then n² lines of n² numbers.
**Output** (`output.txt`): `Correct` or `Incorrect`.

Examples: the 9×9 sample → `Correct`, `1 / 10` → `Incorrect`.
