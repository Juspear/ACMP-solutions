# Carousel

In a carousel contest the first problem is worth 3 points. A correct answer earns the
current cost and makes the next problem 1 point more expensive. A wrong answer earns
nothing and makes the next problem 3 points cheaper, but never below 3 points. Given
the sequence of a team's answers, compute its final score.

**Input** (`input.txt`): N (N ≤ 10^5), then N digits 0 or 1, where 1 means a correct answer.
**Output** (`output.txt`): the total score.

Examples: `3 / 1 1 1` → `12`, `9 / 1 0 1 1 1 1 0 1 1` → `30`.
