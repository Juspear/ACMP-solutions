# Hockey

N teams take part in a hockey tournament. Count the number of ways to hand out the gold,
silver and bronze medals if each place goes to a different team.

**Input** (`input.txt`): an integer N (1 ≤ N ≤ 10^4).
**Output** (`output.txt`): the number of ways.

Examples: `3` → `6`, `20` → `6840`.
