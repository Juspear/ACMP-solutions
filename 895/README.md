# Tic-tac-toe

A finished game of tic-tac-toe on a 3×3 board is given. X always moves first. The game ends
as soon as someone gets three in a row (horizontally, vertically or diagonally), or as a draw
when the board is full. Determine the result for the first player.

**Input** (`input.txt`): three lines of three characters each: `X`, `O` or `.` (empty cell).
**Output** (`output.txt`): `Win`, `Lose` or `Draw`.

Examples: `.OX/.XO/XXO` → `Win`, `OXO/.OX/OXX` → `Lose`, `XOX/XOX/OXO` → `Draw`.
