# Nice pattern

A 4×4 floor is tiled with black and white square tiles. The pattern is considered nice if
there is no 2×2 square made entirely of tiles of the same colour. Check whether the given
pattern is nice.

**Input** (`input.txt`): 4 lines of 4 characters each, `W` for a white tile and `B` for a black one.
**Output** (`output.txt`): `Yes` if the pattern is nice, `No` otherwise.

Examples: `BWBW / BBWB / WWBB / BWWW` → `Yes`, `BBWB / BBWB / WWBW / BBWB` → `No`.
