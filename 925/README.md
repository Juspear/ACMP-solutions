# Casting

A theater has n actors: a of them are tall, b are blue-eyed and c are blond. The director
needs a tall blue-eyed blond. Find the minimum or the maximum possible number of actors
who have all three traits.

**Input** (`input.txt`): 1 (find the minimum) or 2 (find the maximum) on the first line, then n, a, b, c
(1 ≤ n ≤ 10 000, 0 ≤ a, b, c ≤ n).
**Output** (`output.txt`): the requested minimum or maximum.

Examples: `2` / `5 3 4 5` → `3`, `1` / `5 3 4 5` → `2`.
