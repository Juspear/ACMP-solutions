# Dice

On a standard die opposite faces sum to 7. The first player rolls any number of dice and
scores the sum of the top faces, the second player scores the sum of the bottom faces.
Knowing only the first player's score n, find the minimum and maximum possible score of
the second player.

**Input** (`input.txt`): one natural number n (n ≤ 10^10).
**Output** (`output.txt`): the minimum and maximum score of the second player.

Examples: `2` → `5 12`, `36` → `6 216`.
