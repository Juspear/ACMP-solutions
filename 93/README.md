# Gods

Copies of ancient manuscripts contain names of gods, and every name was written with exactly
one wrong letter (one letter replaced by another). Given the list of correct names and the list of
suspicious words, count for each god how many suspicious words are his name with exactly one mistake.

**Input** (`input.txt`): N, then N names, then M, then M suspicious words; all are strings of K uppercase English letters (1 ≤ N, M, K ≤ 30).
**Output** (`output.txt`): N numbers — the count for each god.

Examples: `3 / ZEUS / POSEIDON / AFINA / 4 / ZEVS / POSEYDON / AVYNA / ZERS` → `2 1 0`.
