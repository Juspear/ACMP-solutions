# Telephone

Phone calls cost B rubles per minute for the first A minutes of the month, and every minute
beyond that costs C rubles. Compute the monthly bill for T minutes of calls.

**Input** (`input.txt`): four positive integers A, B, C, T (each at most 1000).
**Output** (`output.txt`): the monthly payment.

Examples: `30 2 3 30` → `60`, `20 1 3 30` → `50`.
