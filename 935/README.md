# Chessboard

Given the coordinates of two cells on a standard 8×8 chessboard, determine whether they
have the same color.

**Input** (`input.txt`): four integers x1, y1, x2, y2 (1 ≤ x1, y1, x2, y2 ≤ 8).
**Output** (`output.txt`): `YES` if the cells are the same color, otherwise `NO`.

Examples: `1 1 4 4` → `YES`, `1 2 7 5` → `NO`.
