# Prince and dragon

A sword cuts off N heads per strike, the dragon starts with M heads and regrows K heads
after every strike that does not finish it. The prince wins as soon as a strike leaves the
dragon with no heads. Find the number of strikes needed or report that it is impossible.

**Input** (`input.txt`): three integers N, M, K (1 ≤ N, M, K ≤ 10^5).
**Output** (`output.txt`): the number of strikes, or `NO` if the dragon cannot be killed.

Examples: `3 6 2` → `4`, `4 4 5` → `1`, `5 10 6` → `NO`.
