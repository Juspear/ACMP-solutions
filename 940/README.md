# Spelling

Petya writes every word with exactly one extra letter. Given the position K of the
extra letter and the word S (uppercase English letters, length up to 80), remove that
letter and print the corrected word.

**Input** (`input.txt`): an integer K and, after one or more spaces, the word S.
**Output** (`output.txt`): the word without its K-th letter.

Examples: `4 MISTSPELL` → `MISSPELL`, `2 ABC` → `AC`.
