# Snake - 3

An N×M matrix is filled with numbers starting from 0 row by row in a snake pattern:
odd rows go left to right, even rows go right to left. Find the value standing in row Y,
column X.

**Input** (`input.txt`): four integers N, M, Y, X (Y ≤ N ≤ 50, X ≤ M ≤ 50).
**Output** (`output.txt`): the value of the element in row Y and column X.

Examples: `3 4 2 3` → `5`, `5 2 3 1` → `4`, `3 4 3 2` → `9`.
