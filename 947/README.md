# Cards - 3

Stacking N cards on the edge of a table, the stack overhangs by 1/2 + 1/3 + ... + 1/(N+1)
of a card length. Given a target length X, find the smallest number of cards whose
overhang is at least X.

**Input** (`input.txt`): a positive number X with two digits after the decimal point (0.01 ≤ X < 10.00).
**Output** (`output.txt`): the answer in the form `N card(s)`.

Examples: `1.00` → `3 card(s)`, `3.71` → `61 card(s)`, `0.04` → `1 card(s)`, `5.19` → `273 card(s)`.
