# Lines in a book

Each page of a book holds K lines: page 1 has lines 1..K, page 2 has lines K+1..2K, and so
on. Given the line number N, find the page it is printed on and its position on that page.

**Input** (`input.txt`): two integers K and N (1 ≤ K ≤ 200, 1 ≤ N ≤ 20000).
**Output** (`output.txt`): the page number and the line number on that page.

Examples: `50 1` → `1 1`, `20 25` → `2 5`, `15 43` → `3 13`.
