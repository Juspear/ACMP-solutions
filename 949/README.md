# Fibonacci-like sequence

A sequence is Fibonacci-like if every term starting from the third equals the sum of the
two previous ones. Given n and the terms a_n and a_(n+1), restore the first two terms.

**Input** (`input.txt`): n, a_n and a_(n+1) (1 ≤ n ≤ 30, all terms up to 2·10^9 by absolute value).
**Output** (`output.txt`): a_1 and a_2.

Examples: `4 3 5` → `1 1`.
