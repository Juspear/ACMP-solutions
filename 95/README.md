# Numerologist

A numerologist takes a number and replaces it with the sum of its digits, repeating this until
a single digit remains. Given the (possibly huge) number, output the resulting digit and the
number of operations performed.

**Input** (`input.txt`): the number N (1 ≤ N ≤ 10^1000).
**Output** (`output.txt`): the final digit and the number of transformations, separated by a space.

Examples: `1` → `1 0`, `10` → `1 1`, `99` → `9 2`.
