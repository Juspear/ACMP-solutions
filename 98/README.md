# Number game

Two players take turns removing a number from either end of an array, always taking the
larger of the two end values (the left one on a tie). Each player sums the numbers they
removed. Compute both final scores.

**Input** (`input.txt`): N (1 ≤ N ≤ 10^4) and then N positive integers up to 32000.
**Output** (`output.txt`): the first player's score and the second player's score separated by a colon.

Examples: `4 4 1 5 4` → `9:9`, `1234` → `1234:0`.
